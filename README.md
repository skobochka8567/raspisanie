# Расписание

Присылает уведомления с парами на день, временем выхода из дома, погодой
и что взять с собой. По умолчанию — два уведомления: вечером (про завтра)
и рано утром (финальное напоминание про сегодняшний день).

## Как запустить

1. Загрузи все файлы из этой папки в репозиторий на GitHub (сохрани структуру).
2. Вкладка **Actions** — сборка запустится автоматически при пуше в `main`
   (или вручную кнопкой **Run workflow**).
3. Когда сборка позеленеет, зайди в неё → **Artifacts** → скачай `raspisanie-apk`
   (внутри `app-debug.apk`).
4. Перекинь APK на телефон, разреши установку "из неизвестных источников", установи.
5. Открой приложение, разреши уведомления, нажми
   **"Включить ежедневные уведомления"**. На Android 12+ может появиться
   системная просьба разрешить точные будильники — подтверди.

## Как изменить расписание и настройки

Всё в одном файле: `app/src/main/assets/config.json`.
Открой на GitHub (карандаш), поправь, сделай commit — Actions пересоберёт APK.

Поля:

- `reminders` — список напоминаний. У каждого: `hour`/`minute` — время,
  `days_ahead` — на сколько дней вперёд смотреть расписание
  (1 = про завтра, 0 = про сегодня). Можно добавить сколько угодно
  напоминаний, не только два
- `travel_minutes` — сколько в среднем идёт дорога
- `prep_minutes` — сколько нужно на сборы
- `home_lat`, `home_lon` — координаты дома (для погоды)
- `exempt_subjects` — предметы, на которые у тебя освобождение — они всегда
  помечаются "не идёшь" и не влияют на время выхода
- `always_bring` — что брать каждый раз, когда в этот день есть хоть одна пара
- `period_times` — время начала/конца каждой пары по номеру (одинаковое
  каждый день)
- `week_schedule` — расписание по дням недели. У каждой пары: `period`
  (номер пары), `subject` (предмет), `online` (true — если дистанционно,
  тогда ехать никуда не надо). Пустые номера между парами автоматически
  становятся "окно" в уведомлении
- `items_by_subject` — что брать, если в этот день есть конкретный предмет
  (кроме `always_bring`, который добавляется всегда)

Погода — с бесплатного Open-Meteo, ключ не нужен.

Расписание в вузе обычно меняется каждую неделю — значит, `week_schedule`
тоже нужно будет обновлять примерно раз в неделю (просто правишь текст
и коммитишь, 1-2 минуты).

## Если сборка в Actions упала

Открой лог упавшего шага, скинь текст ошибки — поправлю файлы.
