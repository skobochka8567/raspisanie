# Расписание

Приложение раз в день (по умолчанию — в 20:00) присылает уведомление:
пары на завтра, время выхода из дома, погода и что взять с собой.

## Как запустить

1. Создай новый репозиторий на GitHub и загрузи в него все файлы из этой папки
   (сохрани структуру папок как есть).
2. Открой вкладку **Actions** в репозитории — сборка запустится автоматически
   при пуше в ветку `main` (или запусти вручную кнопкой **Run workflow**).
3. Когда сборка завершится (зелёная галочка), зайди в неё и в разделе
   **Artifacts** скачай `raspisanie-apk` — внутри будет `app-debug.apk`.
4. Перекинь APK на телефон, разреши установку "из неизвестных источников"
   и установи.
5. Открой приложение, дай разрешение на уведомления, нажми
   **"Включить ежедневные уведомления"**. На Android 12+ может появиться
   системная просьба разрешить точные будильники — подтверди её.

## Как изменить расписание, адрес и погоду

Всё настраивается в одном файле:
`app/src/main/assets/config.json`

Открой его прямо на GitHub (кнопка карандаша), поправь и сделай commit —
Actions сама пересоберёт APK за 2-3 минуты.

Поля:

- `notify_hour`, `notify_minute` — время, когда присылать уведомление
  (по умолчанию 20:00, вечером — про завтрашний день)
- `days_ahead` — на сколько дней вперёд смотреть расписание
  (1 = уведомление вечером про завтра; поставь 0, если хочешь настроить
  уведомление рано утром про сегодня)
- `first_period_time` — время начала первой пары
- `travel_minutes` — сколько в среднем идёт дорога
- `prep_minutes` — сколько нужно на сборы
- `home_lat`, `home_lon` — координаты твоего дома (для погоды).
  Проще всего найти: открой Google Maps, зажми точку на своём доме —
  внизу появятся координаты, скопируй первые два числа
- `week_schedule` — расписание по дням недели. Порядок предметов в списке —
  это и есть номера пар по порядку
- `items_by_subject` — что брать, если в этот день есть такой предмет
  (можно оставить пустым `{}`, если не нужно)

Погода берётся с бесплатного сервиса Open-Meteo, ключ не нужен.

## Если сборка в Actions упала с ошибкой

Открой лог упавшего шага и пришли мне текст ошибки — поправлю файлы.
